개인정보처리방침 (Privacy Policy)

시행일: 2026-10-02

1. 접근하는 정보

hermes-calendar는 Google 캘린더 일정 권한(calendar.events) 하나만 요청합니다. 접근 대상은 앱 소유자 본인의 캘린더 일정(제목·시간·장소·설명)뿐입니다.

2. 이용 목적

소유자 본인의 일정 조회·등록·수정과 일정 알림 발송에만 사용합니다. 광고·분석·판매 목적으로 사용하지 않습니다.

3. 보관과 공유

인증 토큰은 소유자 전용 서버에 소유자만 읽을 수 있는 권한으로 보관합니다. 일정 정보를 제3자에게 제공하거나 판매하지 않습니다. Google API에서 받은 정보의 사용은 Google API Services User Data Policy(Limited Use 요건 포함)를 따릅니다.

4. 권한 철회

Google 계정 > 보안 > 서드파티 액세스(myaccount.google.com/permissions)에서 언제든 철회할 수 있으며, 철회 시 보관 중인 토큰은 더 이상 쓰이지 않고 삭제됩니다.

hermes-calendar requests only the Google Calendar events scope, accesses only its owner's own calendar, uses the data solely to manage the owner's events and reminders, does not share or sell it, and complies with the Google API Services User Data Policy including Limited Use requirements. Access can be revoked at any time from Google Account permissions.
